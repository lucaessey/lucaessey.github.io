FROM YIPS TO NERPS
Story by Luca. A static illustrated comic and five-level Guess the Rock game.

EDITING THIS EDITION
story.js: 8 chapters and 64 panels, narration, speech, labels and scene metadata.
descriptions.js: plain-language descriptions for all 64 illustrations.
reader.js: chapter navigation, progress, reading bookmarks, and enlargement.
style.css: reader layout and editable lettering over illustrations.
game.html, game-play.js, game-core.js, game.css: game controls, animation, and rules.
transcript.html: complete standalone transcript that works without JavaScript.

ART AND LETTERING
assets/art/sheet-01.webp through sheet-16.webp are original generated sheets.
Each has four equal scenes in a 2-by-2 grid, read left-to-right, then down.
CSS selects each scene; speech and narration are selectable HTML text.
assets/art/cover.webp, game-rock.webp, and game-yip.webp supply the cover/game.
Original PNG artwork, prompts, design bible, build scripts and tests are saved
in the Books workspace. Illustrations used the built-in image-generation tool.
Self-hosted Bangers and Comic Neue fonts include SIL Open Font License files.

PUBLICATION
GitHub Pages serves the main branch of lucaessey/lucaessey.github.io at root.
This website lives entirely under /books/ and uses relative resource paths.
Earlier edition files are retained for recoverability and are not loaded by
the current reader. The earlier edition is also preserved in Git history.
Old chapter/game bookmarks remain supported.

Run npm test and npm run build in the Books source workspace before publishing.
Regenerate transcript.html with tools/build.mjs after editing story.js.
Copy the contents of site/ into the publishing checkout's books/ directory.
Commit only books/ and push main. No hosted service or API key is required.
