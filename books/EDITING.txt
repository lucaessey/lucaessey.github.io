FROM YIPS TO NERPS

Story by Luca. This directory is a self-contained static website served at /books/.
Only this directory was added to the existing GitHub Pages repository.

EDITING
story.json contains all 64 panels in reading order: narration, dialogue, image
descriptions, sound effects, and editable signs. Character names such as Stripe
are descriptive accessibility labels, not new names spoken in the story.
Yips speak only Yip. Nerps speak only Nerp. Gorf and narrator text is unrestricted.

The eight chapter-N.webp files are original generated chapter sheets.
Each uses a uniform 2-column, 4-row grid, read left-to-right and top-to-bottom.
The website displays each cell separately using CSS. No panel repeats another
scene. Lettering is selectable HTML, never baked into the art.

After editing story.json, regenerate transcript.html from the same data using
the supplied build-transcript.mjs in the complete source archive. The transcript
works without JavaScript. Keep IDs 1-64 stable to preserve reading bookmarks.

index.html: page structure and game controls.
styles.css: layout, lettering, responsive rules, reduced-motion rules.
app.js: chapter rendering, local reading bookmarks, artwork viewer.
game-engine.js: difficulty settings and identity-based shuffle logic.
game.js: game animation, input, feedback, retry, restart, and celebration.

HOSTING
All asset paths are relative to /books/. No build step, API keys, external
services, or runtime packages are required. No audio or analytics are used.
GitHub Pages publishes the main branch at repository root; pushing changes
under books/ updates https://lucaessey.github.io/books/.

ART AND FONTS
Illustrations were created with the built-in image generation tool using the
author's story and the included art-direction and scene briefs. Bangers and
Comic Neue fonts are bundled with their SIL Open Font License files in assets/.
